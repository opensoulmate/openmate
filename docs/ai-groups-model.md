# AI 群组·产品型态梳理（临时工作小组模型）

> 用户理念定稿 2026-10-23。**单一权威**：AI 群组的产品模型以本文为准。
> 关联：`~/opensoul/docs/feature-placement.md`（归位总图 B4 批次）。

## 一、用户理念（黄金标准）

群组**不是一个固定流程的工作流**，而是类似几个人组成的**临时工作小组**：
**为什么不用系统直接派活（设计依据，用户原话）**：系统直接派活有可能**从一开始分配就出现问题**——
分配必须是集思广益+共识的产物，不是系统硬派。固定阶段（规划/执行/验证/审查）可以有，拆的只是"硬派活"。

1. 先有人**发起群组**
2. **任务发布**到群组后，立即各个 agent **集思广益**制定任务策略并分配任务
3. **达成一致**后，各个 agent **独立完成**
4. 执行过程中**可以在群内讨论**
5. 最终成果**发布到群里再讨论**
6. 满足**事先约定**的结果后，以**正式成果发布**

## 二、现状 vs 理念（差距表）

| 维度 | 现状 | 理念 | 判 |
|---|---|---|---|
| 组织形态 | 任务由系统直接派生阶段子任务，**没有团队协作动态** | 临时工作小组：分工由集思广益+共识产生（固定阶段可有） | ❌ 缺协作动态——不是阶段的问题，是"谁干哪摊"没有商议过程 |
| 任务下发 | 任务→系统直接派活 | 任务发布到群 → 先集思广益再分工 | ❌ |
| 策略制定 | 无此环节 | 集思广益：各 agent 提议策略/分工 | ❌（可复用现有 discussion intents: suggest/claim/refer/comment） |
| 共识 | 无 | 达成一致才开工（分工+验收标准） | ❌ |
| 验收标准 | **事后**评分（review/score） | **事先约定**（共识产物），事后对照 | ❌ 时序颠倒 |
| 执行中讨论 | WS 消息流、@定向、多意图消息 | 群内随时讨论 | ✅ 基本盘在 |
| 成果发布 | 任务 result 字段 | 成果发群→讨论→**正式发布** | ❌ 缺正式发布仪式与归档 |
| 评审/能力 | 任务评审打分/能力档案/综合排名（10-23 接回） | 成员能力沉淀、供下次分工参考 | ✅ 保留并入 S6 |

## 三、目标状态机（七阶段）

```
① 发起群组 ──→ ② 任务发布 ──→ ③ 集思广益 ──→ ④ 共识确认（锁定共识单=事先约定）
                                                    │
                        ⑦ 正式发布 ←── ⑥ 成果讨论 ←── ⑤ 独立执行（群内随时讨论）
                             │                        ▲
                             └── 不满足验收 ──────────┘（回炉迭代）
```

- **共识单**（③的产物、⑦的依据）：分工表（谁干哪摊）+ 验收标准（逐条可勾）+ 截止
- ⑤ 各 agent 独立干活，进度/卡点/疑问发群（现有消息流）
- ⑥ 成果发群 → 质询/讨论
- ⑦ 对照共识单逐条验收 → 满足 → 【正式发布】（成果归档 + 评分 + 能力档案回写）

## 四、改造切片（每片测试绿再下一片）

| 片 | 内容 |
|---|---|
| S1 | 共识单数据模型（分工表/验收标准）+ 群任务卡**阶段徽章**（集思广益/执行中/成果评审/已正式发布） |
| S2 | 集思广益轮：提议消息卡（策略/分工/验收标准三栏）+ 一键收敛出共识单草案 |
| S3 | 共识确认：成员表态（同意/异议）或发起人拍板 → 共识单锁定 |
| S4 | 共识分工落位：**保留规划/执行/验证/审查固定阶段管线**（用户拍板：固定阶段可以有）；共识单的分工决定谁领哪摊（分工项映射到阶段/子任务），替代"系统硬派活" |
| S5 | 成果发布→讨论→验收：成果消息 + 共识单逐条对照勾验 + 【正式发布】动作（归档/通知/能力回写） |
| S6 | 能力档案/评分与共识联动：历史能力分供集思广益分工参考，正式发布后回写 |

## 五、归位关系

- 界面+API 归 **OpenMate**，编排执行归 **SoulMate**（feature-placement B4）
- **先按新模型实施，随 B4 一次性归位**——不把旧模型搬两遍
- UI 贴「所想即所见」：每阶段在群界面可见、可改

## 六、不变的部分（防误伤）

- 三角色体系（顾问/执行者/验证者/人工）
- 执行时间线、失败重试、任务看板
- 评审打分/能力档案/综合排名（10-23 接回件）——改挂"正式发布"环节
